# 문서함과 검색

## 문서와 폴더

왼쪽 **웹 브라우저 저장소**의 ＋ 메뉴에서 문서와 폴더를 추가합니다. 폴더 메뉴에서는 해당 폴더 안에 항목을 만들 수 있습니다. 각 항목의 메뉴에서 이름 변경·삭제를 할 수 있고, 문서는 다운로드할 수 있습니다.

폴더를 삭제하면 하위 문서와 폴더도 삭제되며 확인 창이 나타납니다. 삭제 전에 필요한 문서는 내보내세요.

항목을 드래그해 순서를 바꾸거나 다른 폴더로 옮길 수 있습니다. 폴더 행 가운데에 놓으면 해당 폴더 안으로, 행 위·아래에 놓으면 그 앞·뒤로 이동합니다. 목록의 빈 곳에 놓으면 최상위로 이동합니다. Alt+위/아래 화살표로 같은 위치의 항목 순서를 바꿀 수도 있습니다.

## 검색

문서함 위 검색창은 모든 폴더의 **문서 제목과 Markdown 원문**을 검색합니다. 닫힌 폴더도 포함하며, 대소문자를 구분하지 않는 문자열 검색입니다.

검색 결과에는 문서 이름, 폴더 경로, 일치한 본문 일부가 표시됩니다. 결과를 누르거나 검색창에서 Enter를 누르면 문서를 엽니다. Escape 또는 지우기 버튼으로 검색을 끝내면 폴더 목록으로 돌아옵니다. 검색어는 저장하지 않으며 오프라인에서도 검색할 수 있습니다.
