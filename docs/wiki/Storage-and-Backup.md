# 저장·가져오기·내보내기

## 자동 저장

문서 내용은 편집 후 약 250ms 뒤 LocalStorage에 저장됩니다. 문서 전환이나 페이지를 떠날 때도 저장을 시도합니다. 저장 공간 부족이나 브라우저 설정으로 저장할 수 없으면 안내가 나타납니다.

문서는 현재 브라우저 프로필과 사이트 출처에 종속됩니다. 브라우저 데이터 삭제·시크릿 모드 종료 등으로 잃을 수 있으므로 중요한 문서는 정기적으로 내보내세요. 소재와 서재 앱은 별도 저장 키를 사용하고 서로 자동 동기화하지 않습니다.

## Markdown 가져오기

**＋ → 업로드하기**에서 UTF-8 `.md` 파일을 여러 개 선택하거나 브라우저 창에 파일을 드롭합니다. 폴더 위에 드롭하면 해당 폴더에, 다른 곳에 드롭하면 최상위에 추가합니다. 같은 이름의 문서가 있어도 덮어쓰지 않고 별도 문서를 만듭니다. 마지막에 가져온 문서가 열립니다.

## 문서 다운로드

문서 메뉴의 다운로드 또는 Ctrl/Cmd+S로 현재 Markdown 문서를 저장합니다. 파일명은 문서 이름을 사용하며 `.md` 확장자가 없으면 붙입니다.

## 전체 문서 내보내기

**＋ → 전체 문서 내보내기**는 `suhjae-documents-YYYY-MM-DD.zip`을 다운로드합니다. 폴더 구조·빈 폴더와 문서 원문을 보존합니다. 중복 파일명에는 번호를 붙이고, 경로에 안전하지 않은 문자는 대체합니다.

ZIP에는 브라우저 설정·실행 취소/협업 기록·외부 이미지 파일이 포함되지 않습니다. ZIP 가져오기는 제공하지 않습니다. 압축을 풀고 Markdown 파일을 가져올 수 있습니다.
