# 서재 · Suhjae

서재는 Markdown 문서를 작성하고 폴더로 정리하는 앱입니다. 소재(Sohjae) 에디터를 기반으로 하며, 이 Wiki는 **서재 앱의 사용법과 운영 방식**만 다룹니다.

**[웹앱 열기](https://mson0129.github.io/suhjae/)**

- [시작하기](Getting-Started)
- [문서함과 검색](Documents-and-Search)
- [편집과 읽기](Editing-and-Reading)
- [저장·가져오기·내보내기](Storage-and-Backup)
- [오프라인과 탭 동기화](Offline-and-Sync)
- [플랫폼과 개발·배포](Development-and-Platforms)

현재 배포된 버전은 웹앱입니다. 문서는 현재 브라우저의 LocalStorage에 저장됩니다. 서버 계정, 클라우드 백업, 다른 기기와의 자동 동기화는 제공하지 않습니다.

소재 SDK의 API·Rust·WASM 구현 설명은 [소재 저장소](https://github.com/mson0129/sohjae)에서 관리합니다.
