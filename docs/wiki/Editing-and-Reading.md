# 편집과 읽기

오른쪽 위 **화면** 메뉴에서 네 가지 구성을 선택합니다.

| 화면 | 용도 |
| --- | --- |
| 풀사이즈 에디터 | 리치·하이브리드·스타일 Markdown 방식으로 편집 |
| 마크다운 + 미리보기 | 스타일 Markdown과 렌더링 결과를 함께 보기 |
| 원문 + 미리보기 | 일반 원문과 렌더링 결과를 함께 보기 |
| 읽기 | 편집 영역 없이 문서와 목차 보기 |

하이브리드 편집은 기본 편집 방식입니다. 화면 구성 전환은 현재 문서의 편집기와 실행 취소 상태를 유지합니다. 문서 전환은 해당 문서의 편집 세션을 시작합니다.

## 목차와 스크롤

미리보기·읽기 화면의 오른쪽 목차는 H1–H6 제목을 계층별로 표시합니다. 제목을 누르면 해당 위치로 이동하고, 현재 화면에 보이는 제목들을 강조합니다.

분할 화면에서 **동시 스크롤**을 켜면 두 영역의 상대적인 스크롤 위치를 맞춥니다. 원문 행과 미리보기 문단을 정확히 대응시키는 방식은 아닙니다. 끄면 각 영역을 독립적으로 스크롤합니다.

## 테마와 인쇄

상단 테마 버튼으로 앱의 밝은 화면·어두운 화면을 전환합니다. 읽기 화면에서는 별도로 10가지 읽기 테마를 선택할 수 있습니다. 테마는 문서 원문을 변경하지 않습니다.

브라우저 인쇄 기능은 현재 문서 본문만 출력합니다. 문서함·도구 모음·목차는 제외되며, 선택한 테마와 관계없이 흰 종이에 어두운 글자로 출력합니다.
