# 오프라인과 탭 동기화

## 오프라인 사용

처음 온라인으로 방문하면 앱 화면, 편집기·렌더러와 WASM을 Service Worker 캐시에 다운로드합니다. 다운로드 완료 후에는 네트워크 없이 앱 열기, 편집, 미리보기, 검색, 브라우저 저장·복원을 사용할 수 있습니다.

HTTPS 또는 localhost에서 동작합니다. 외부 이미지와 링크 대상 사이트는 캐시하지 않으므로 오프라인에서 표시되지 않을 수 있습니다. 브라우저 데이터 삭제 시 오프라인 캐시도 사라집니다.

앱 업데이트는 온라인 재방문 시 내려받습니다. 기존 앱 탭을 모두 닫은 후 다시 열면 대기 중인 새 버전이 활성화됩니다.

## 같은 브라우저의 탭 동기화

같은 브라우저 프로필에서 서재를 여러 탭·창으로 열면 문서 내용과 문서함 변경 사항이 자동으로 공유됩니다. 서버·방 초대·STUN/TURN 설정은 필요하지 않습니다.

각 탭은 열린 문서, 화면 구성, 편집 모드와 선택 위치를 독립적으로 유지합니다. 문서 내용에는 소재의 협업 기능을 사용합니다.

이 기능은 **현재 브라우저 안의 동기화**입니다. 다른 브라우저·프로필·기기와 연결되지 않으며, 일반 창과 시크릿 창도 별도입니다. 서버 백업이나 다른 사람과의 원격 공동 편집 서비스가 아닙니다.
