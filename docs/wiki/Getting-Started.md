# 시작하기

1. [서재 웹앱](https://mson0129.github.io/suhjae/)을 엽니다.
2. 시작 화면의 **편집 시작하기 >**를 누릅니다.
3. 왼쪽 문서함에서 문서를 선택하거나 **＋**로 새 문서·폴더를 만듭니다.
4. 본문을 편집하면 자동으로 브라우저 저장소에 저장됩니다.

처음에는 안내 문서가 열립니다. 새 문서나 폴더를 만들면 이름을 바로 입력할 수 있습니다. 상단 문서 제목을 눌러 이름을 바꿀 수도 있습니다.

페이지를 다시 열면 문서·폴더와 저장된 화면 설정을 복원합니다. 저장 실패 안내가 나오면 문서를 다운로드한 뒤 브라우저 저장 공간을 확인하세요.

기존 소재 웹앱의 문서는 자동으로 옮겨지지 않습니다. 소재 앱에서 전체 문서를 ZIP으로 내보내고 압축을 푼 뒤, 서재에서 `.md` 파일을 가져오세요. 현재 가져오기는 폴더 ZIP 복원이 아니므로 폴더 구조는 직접 구성해야 합니다.
